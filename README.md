# Calculatrice

Une calculatrice simple réalisée en HTML, CSS et JavaScript.

## Fonctionnalités
- Addition, soustraction, multiplication, division
- Gestion des erreurs (division par zéro, etc.)

## Technologies
- HTML5
- CSS3
- JavaScript

## Installation
Ouvrir le fichier `index.html` dans un navigateur.
